# data/ — 質問データ（推理ロジックと分離）

Phase 2 で作成する。構造の詳細は `docs/phase0/design.md` 6章。

| パス | 内容 |
|---|---|
| `questions/` | ジャンル別の質問（12ファイル） |
| `subjects/` | 作品・商品・出来事の「事実」（発売・普及・流行時期、対象年齢）。複数の質問から参照する |
| `sources.json` | 出典の一覧（名称・発行者・URL・確認日・信頼性） |
| `generations.json` | 世代分類の定義（出典付き） |
| `schema/` | データ形式の定義（エディタでの入力補完・検証用） |

**ルール**：出典で確認できない事実は登録しない（`status: draft` のまま公開しない）。
