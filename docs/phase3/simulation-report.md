> `npm run simulate` で自動生成。手で編集しない。
> **仮想回答者による結果であり、実際の人に対する精度ではない。** 実際の精度は限定公開テスト（Phase 9）で測定する。

## 1. 条件

- 質問データ：201問／基準年 2026／回答者：10〜90歳の各生年 3人（243人／シナリオ）
