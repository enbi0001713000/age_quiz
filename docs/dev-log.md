### 発生した問題と解決
- **日付の精度の違いで誤ってエラー**（たまごっち：流行開始「1996-11」と発売日「1996-11-23」）→ 精度の粗い方にそろえて比較するよう検査を修正
- **ポケベルの中心世代が古く出た**（業務用の時代 1968〜1986年を「普及途中」として扱っていたため）→ 中心期の直前2年だけを「普及途中」、それより前は「一部の人だけ」（低い値）とするようモデルを修正
- **消費税の導入年（1989年4月）を「消費税なし」と数えていた** → 年単位の計算で、上半期に終わったものは前年まで、下半期に始まった流行は翌年からとみなす丸め規則を追加（テストで確認）
- **8cmCDシングルの期間を手入力した値（〜2001年）が、規則に従った再計算（〜2003年）と不一致** → 再計算テストで検出し、規則どおりの値に修正（2003年の一時的な増加は規則文に注記）

### 限界・未解決事項（重要）
1. **モデル値の多くが推定値**：事実はすべて出典付きだが、経験確率の計算に使う「何歳ごろに経験したか（年齢窓）」は79件中77件、「中心世代での経験率の上限」は76件が根拠付きの推定値。流行の終わりの年も34件が推定。→ Phase 3 で、これらを変えたときに推定結果がどれだけ変わるか（感度）を確認し、Phase 9 の実地テストで校正する。Phase 6 では玩具の「対象年齢」表示など、利用者層の出典を優先的に探す
2. **識別力の偏り**：1930年代・2010年代生まれを見分ける質問が少ない（分析レポート2章）。高齢層向けは「〜歳以上なら知っている」型の質問に偏っており、1930〜50年代の中を細かく分けられない → Phase 6 で補強
3. **携帯の時代選択（MOB-001）**：ポケベルの中心世代がやや古め（1967〜1977年生まれ）に出る。携帯電話の普及期と重なるため。Phase 3 のシミュレーションで確認する
4. 曲線が似た質問が7組あるが、題材が独立しているため二重カウントにはならない（出題選択で自然に調整される）。同一の仕組みによる家電2問（エアコン・電子レンジ）は関連質問として設定済み

### パラメータの調整（`docs/phase3/tuning.md`）
- λ（ランダム回答の混合）・τ（温度）・σ（文化的ずれ）の27通りを、評価用とは別のシードで比較
- σ=1.0 は「高」が増えるが、「高」で誤差3年超が11〜25%となり目標（10%以下）を満たさないため不採用
- 結果として **Phase 0 の初期値（λ=0.08、τ=0.8、σ=1.5）が最良** だったため変更なし

### 感度分析（Phase 2 の限界「モデル値の多くが推定値」への対応）
- 年齢窓・経験率上限の誤差を ±0年／×1 から ±4年／×0.4〜1.6 まで大きくしても、平均誤差は 2.0→2.3年、±5年以内は93〜96% とほぼ維持
- ただし誤差が最大のときは「高」で誤差3年超が13%に増える → 実地テストでの校正が重要

### 発生した問題と解決
- **起動時の計算に1.4秒かかった** → 対象ごとの活動度の表を1回だけ計算して使い回すようにし、約0.09秒に短縮
- **1点に集中した推定の80%区間が偏った（1988〜1991年）** → 同じ確率の生年は区別できないため、まとめて区間に含める規則にした（テストで確認）
- **「1回答による推定の移動」の指標が不適切だった**（最初の回答は推定が全年代に広がっているため大きく動くのが当然）→ 最終推定から1問ずつ除いて推定し直す指標に変更

### 判断事項（軽微・設計からの変更）
- 候補が離れた年代に分かれている場合は、80%区間が狭くても確信度を「高」にしない
- 推定生年（点推定）は中央値。候補が分かれている場合は、確率が最も大きい山の中での中央値
- `InferenceSession` に基本質問の出題順を固定するオプションを追加（テスト・検証用。通常はランダム）

### POに判断をお願いしたい事項
- **確信度「高」がほとんど出ない（約2%）**：多くの結果は「1988〜1993年生まれ」のような範囲表示になる。「高」の基準を80%区間6年以下に緩めると「高」は21〜34%に増えるが、ずれが大きい条件で「高」なのに3年超外れる割合が22%となり目標を満たさないため、現状（5年以下）を推奨。Phase 6 の質問追加と実地テストの校正で改善を見込む

### 未解決事項

- 1問を除いたときの変化が最大14〜17年になる例がある（候補が2つの年代に分かれていたケース）。95%点は3〜5年
- 「ずれ：小」で80%区間がやや広め（正解が入る割合91%）。実地テストで σ を再調整する
