# age_quiz — 年齢推理ゲーム（仮称）

質問への回答から、子どもの頃に触れた文化的経験（ゲーム・アニメ・テレビ・携帯電話・学校生活など）を手掛かりに、回答者の**生年**を確率的に推理するブラウザゲーム。

- 公開先：GitHub Pages（静的サイト・サーバー不要）
- スマートフォン優先／PC対応／オフライン対応予定
- 個人情報は外部に送信しない。外部AI APIは使用しない

## 現在の状況

**Phase 0（要件理解・技術設計）— プロダクトオーナーの承認待ち**

アプリ本体のコードはまだありません。
